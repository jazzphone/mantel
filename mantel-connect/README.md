Install, set up and update: [Mantel Connect](https://github.com/jazzphone/mantel/blob/v0.1.166/docs/guide/Mantel-Connect.md).
This folder is generated at each release from [packaging/connect-app](https://github.com/jazzphone/mantel/tree/v0.1.166/packaging/connect-app).
