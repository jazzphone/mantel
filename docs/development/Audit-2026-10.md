# Engineering audit, October 2026

A full-system audit and stabilization pass over Mantel at 0.1.37. This page is the working plan and the issue
register: what was looked at, what was found, what was fixed and how it was checked, and what is left. It is
kept up to date as the work goes, so an interrupted pass can pick up from here.

## Baseline (before any change)

| Check | Result |
|---|---|
| Main suite, `pytest -q` (Python 3.12, Linux) | 3117 passed, 6 skipped |
| `tools/check_links.py` | 75 files, 0 broken links |
| `tools/package_check.py` | clean |
| `tools/check_version.py` | 0.1.37 everywhere |

Skipped in this environment, and why: the Mac's QR reader (CoreImage); the private-words check (no list given);
Home Assistant's test venv (`~/.venvs/hk-ha-test`, Python 3.14) for Mantel Link's suite and the linked
end-to-end tests; Caddy; Chrome for the settings viewports test (Chromium exists here but is not on `PATH`).

## Plan

1. Discovery: the pieces, the history, the high-risk areas. **Done.**
2. Subsystem audits, each traced end to end: sign-in and sessions; roles, the gateway and filtering; the doors
   (proxies, tunnel, Access, Ingress, Connect); media (music, cameras, Live TV, photos, files); tablets, Mantel
   Link and push; persistence, configuration, backups and packaging; the features and `hk_core`; the browser side.
3. Register the verified findings below, P0 first.
4. Fix, with a regression test per fix; rerun the suite after each batch.
5. Docs reconciled with the code.
6. Final regression: the main suite, the static checks, the headless checks this environment can run.

## Issue register

Severity: **P0** unauthorized home control, credential disclosure, data loss; **P1** broken core function,
authorization inconsistency, corruption risk; **P2** functional bug, material maintainability or performance
problem; **P3** minor.

Every finding below was traced end to end and reproduced (a test against the running app, a Node harness or a
headless browser) unless the row says otherwise.
