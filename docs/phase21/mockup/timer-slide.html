Four things found while reading the code

  • Nothing rings today. The quick-timer helpers were left unwired on purpose ("each home's own automation"), so this is new behavior.
  • The house has 41 timer entities, most of them automation plumbing. Only timers you set will count, or a fan's hold timer would take over the wall. House Timers such as Night and Nap are always ignored.
  • "Idle" also means canceled. The existing "timer ends" notification also fires when you cancel. Here the timer counts as ended only if its deadline really passed, so Cancel and Finish stay silent.
  • A slide can't run alone yet. A screen with no slides turned on never starts the slide clock. Running timers must start it, or the Timers slide would never come.

Build order

  1. The slide. Rings, sub timers, every-other-turn, the last-minute hold, five screen sizes. Silent.
  2. Timers on the server. Create and delete real Home Assistant timers, store the room, detect a real end, clean up leftovers, survive a restart.
  3. Tablet sound and Time's Up. Tone, Stop, +1 Min, Restart, and the pop-up when someone is using the tablet.
  4. HomePods. Room lookup, music dipping, volume, a bad speaker falling back to the tablet.
  5. Settings and docs. The editor row, the Timers page section, Rings In, the guide, the checks.

Inside Home Assistant, HK Frontend gets the slide and says "Sound needs Mantel", as its Intercom block does.

Not proven until it runs on the house

  • Creating, renaming and deleting a timer on a running Home Assistant. Its code says this works and the entity id stays the same. I'll prove it on the scratch Home Assistant first, not on the house.
  • How late a HomePod starts after 0:00. The tablet will be first, and I expect a gap of a few seconds. I'll measure it and start the speaker early if it's bad.
  • Whether each tablet's kiosk lets sound play with no tap. If not, it shows the Intercom's "Tap to hear" pill once.
  • Whether a ring moving once a second stays smooth on the wall tablets. The other slides hold still on purpose, so this needs measuring.
