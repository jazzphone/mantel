# Code of conduct

Mantel follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be kind, assume good intent, and keep discussion about the work.

If someone's behavior in an issue, pull request or discussion here bothers you, tell the maintainer privately through GitHub (**Security** → **Report a vulnerability** works for anything sensitive). Reports are kept confidential.
